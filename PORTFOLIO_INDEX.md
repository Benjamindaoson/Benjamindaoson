## Maintenance rules｜维护规则

1. Integrated Lab pages navigate and explain; they do not duplicate a flagship repository.
2. Every project uses one public status: **Flagship, Research, Active Build, Case Study, Teaching, Legacy, or Archived**.
3. Private research is described by direction only; inaccessible code links are not published.
4. A flagship release, rename, visibility change, or archive must update this index and the relevant integrated Lab page in the same maintenance pass.
5. No repository is deleted until unique content, history, links, licenses, and successor mapping are verified.
6. Implemented behavior, measured evidence, production-shaped architecture, and real production deployment are reported separately.
